# Product Brief: SkillBridge Explorer

## Context
SkillBridge is a modern web application designed for university and college students seeking legitimate, verified tech internships, remote contracts, and early-career professional opportunities.

## Problem
Students currently rely on scattered spreadsheets, unverified social media posts, and chaotic email chains to discover and apply to opportunities. This fragmented ecosystem leads to missed deadlines, lack of transparency, and vulnerability to scam listings.

## Target Users
- **Primary Users**: University and college students (ages 18–24).
- **Characteristics**: Mixed technical comfort, highly mobile-dependent, seeking streamlined and trustworthy application pathways.

## Goals
- Provide a single, reliable, fast, and accessible web frontend for discovering and applying to tech opportunities.
- Eliminate layout shifts (CLS = 0) and ensure lightning-fast navigation.
- Implement robust client-side validation and local storage persistence for tracking applications without requiring a heavy backend.

## Constraints & Assumptions
- Built using free tools only (React, Vite, React Router, Vitest/RTL, and JSONPlaceholder public API).
- Simulated backend (localStorage used for "My Applications" state management).
